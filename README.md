# Jaktlaget 1.4.0

Bygger vidare på 1.3.1 och migrerar lokal data automatiskt.

## Nytt
- Ren startsida under Mer och Inställningar.
- Genomförda jakter med vakjakt, pyrschjakt och drevjakt.
- Jaktdagar per medlem samt namngivna gäster.
- Viltobservationer med art, klass, flockstorlek, halvtimme, observatör, plats och riktning.
- Kassationer är ren sidoinformation och ingår inte i registrerade djur eller statistik.
- Kompaktare kalender och stabila formulärknappar.
- Framtidssäker JSON-modell för koordinater, kartcell, GPX och senare köttviktsfördelning.

Ladda upp samtliga filer i ZIP-paketet till roten av GitHub-repositoryt och ersätt äldre filer.
